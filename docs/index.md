## Documentation Structure

| Section | Location | What you will find |
|---------|----------|-------------------|
| **Tutorials** | `docs/tutorials/` | Step-by-step walkthroughs for beginners. Start here if you are new to Cleat. Covers quick start, building your first workflow, and working with signals. |
| **How-To Guides** | `docs/how-to/` | Practical, goal-driven guides. Learn how to use plugins, test workflows, set up multi-tenancy, and more. |
| **Reference** | `docs/reference/` | Technical reference material: CLI commands, SDK API documentation, worker configuration flags, and database schema. |
| **Explanation** | `docs/explanation/` | Deep dives into Cleat's architecture, execution model, WASM compilation pipeline, security model, and plugin system. |
| **Operations** | `docs/operations/` | Production deployment guides, disaster recovery procedures, zero-downtime upgrades, and operational runbooks. |
| **Migration Guides** | `docs/migration/` | Step-by-step migration paths from Temporal, DBOS, and Restate to Cleat. |
| **Project** | `docs/project/` | Project roadmap, status, release process, and governance. |
| **Contributor Guide** | `CONTRIBUTING.md` | How to set up a development environment, coding standards, and the pull request process. |
