## Key Findings by Item

### 1. ChildWorkflow API ($15)

Three overlapping APIs identified. `ChildWorkflowWithOptions` is canonical but used
in only 1 production location (dag plugin). `ChildWorkflow` is the base primitive
(17+ call sites, mostly tests). `ChildWorkflowTyped` is a convenience wrapper
(1 production use). Options silently dropped in localdev runner.

Neither ARCHITECTURE.md nor ABI.md documents any of these APIs.

Action: document preferred API, update benchmark, wire localdev, ~50 lines across 4-5 files.

### 2. Multi-DB ($20)

Root cause: `auth/tenant_store.go` has 3 hardcoded PostgreSQL-only queries using
`admin.` schema, `$N` placeholders, and `RETURNING`. No dialect awareness exists
in auth/ or plugin/ packages. MySQL/MSSQL CI tests silently skipped (env vars not set).
Migration count differs across backends (9/7/8).

Store implementations (db.go, mysql_store.go, mssql_store.go) are correct —
the gap is in auth and plugin packages that don't use the store interface.

### 3. SDK Tests ($15)

Rust: well-tested (25 unit + 7 integration + 5 compile-fail). 4 ABI.md mismatches:
- 2 sections missing `priority` parameter
- 2 host imports (`cleat_poll_child`, `cleat_await_any_child`) entirely missing from ABI.md

AssemblyScript: test harness provides JS stubs for only 2 of 50+ host imports.
11 known issues from fork/port. No tests exercise HostCalls methods beyond JSON.

Python: 9 test files, ~100+ unit tests (CleatTestHarness). BUT WASM E2E NEVER validated.
`TestPythonWasmEndToEnd` always skipped. CI path mismatch in e2e-cross-language.yml
(`./internal/host/...` but tests are in `engine/` and `tests/cross-language/`).

### 4. CI ($15)
