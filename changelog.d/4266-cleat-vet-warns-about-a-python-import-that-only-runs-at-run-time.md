- **`cleat vet --lang python` and `cleat build --target python` now warn about a standard-library import that only happens when the workflow runs (cleat#4266).** componentize-py keeps only the standard-library modules that were imported while the component was being built, so `import csv`, `difflib`, `textwrap`, `pprint` and most of the rest of the standard library, imported inside a function, raised `ModuleNotFoundError` at run time and not at build time. Two new warnings, which never refuse a build and never change the exit status: **PY014** flags a standard-library `import` inside any function, and **PY015** flags the calls measured to import a module on first use (`strptime` needs `_strptime`, `Counter.most_common` needs `heapq`, and the `cp1252`, `shift_jis`, `iso-8859-15`, `utf-8-sig` and `idna` codecs need their `encodings` module), each naming the module to import at the top level of the workflow module. Codecs and calls that were not measured are not flagged.
