- **An agent workflow no longer sends an approval tool's raw output to the model, and the in-process `WaitForEvent` no longer prints the awaited plugin's output in its error (cleat#4390).** When an approval tool answered with something that is not JSON, `agentworkflow` put that output into the tool error, and a tool error is reported to the model on the next turn (unless the caller chose `ToolErrorFail`) and recorded in the `ToolCalls` the run returns, so a third-party model was handed whatever the approval plugin had produced, possibly after the engine had decrypted it. The in-process `WaitForEvent` used by `cleattest`, `localdev` and `embedded` printed the awaited function's output when it was not claim-shaped, the same text the engine's own copy stopped printing (cleat#4321). Both now name the output by its size and the start of its SHA-256, as `[redacted: <n> bytes, sha256=<16 hex digits>]`, so two messages can still be compared. A test or tool that read the output out of either error must read it from the plugin call's own record instead.
