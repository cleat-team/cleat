- **The compiled-component cache charges a Python or C# component for what it holds, so by default a worker caches about three distinct Python components instead of six (cleat#4389).** A component was costed at four times its wasm, which under-counted every one measured on 2026-11-23: Python by 1.35 to 1.5 times and C# by up to 2.2 times, because most of a component's wasm is a memory snapshot and not code, so its length does not predict the compiled cost. A component is now costed at 3.5 times its serialized compiled artifact, which tracked the live cost within 2.0 to 3.0 times across five components (a Python component counts about 150 MB, a C# one about 11 to 30 MB). `--wasm-module-cache-max-mb` is unchanged at 512, so a deployment that runs more than three distinct Python workflows will evict and recompile (about 1.5 s each) unless it raises the flag; the reference page has the table and the sizing advice. Core-module workflows (Go, Rust, Java) are charged as before.
