- **A Python workflow can call `datetime.strptime`, `time.strptime`, `Counter.most_common` and the `cp1252`, `shift_jis`, `iso-8859-15`, `utf-8-sig` and `idna` codecs without importing anything extra (cleat#4266).** `componentize-py` keeps only the standard-library modules imported while the component is built, and these calls import a helper (`_strptime`, `heapq`, an `encodings` module) the first time they run, so they raised `ModuleNotFoundError` or `LookupError: unknown encoding` at run time even though the workflow's own imports were all at the top. `cleat_sdk` now imports those helpers, and every workflow imports `cleat_sdk`, so they are in every component. It costs about 0.4 to 0.5 MiB of component size (2.5 to 3 percent, measured on warm builds). `cleat vet`'s PY015 no longer warns for these calls. **This is a short measured list, not a preload of the standard library, and other lazily importing calls are unchanged:** a module that is not imported at the top level of the workflow, and not in this list, is still missing at run time. See the Python SDK README.
