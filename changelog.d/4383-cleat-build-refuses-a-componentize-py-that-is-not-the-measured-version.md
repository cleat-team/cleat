- **`cleat build --target python` now refuses to build with a `componentize-py` other than 0.25.1, and says how to fix it (cleat#4383, cleat#4355).** `componentize-py` decides which standard-library modules a component contains, and the Python SDK's compatibility tables were measured on 0.25.1 and on no other version, so a build with a different one can contain different modules, and a missing module raises `ModuleNotFoundError` only when the workflow runs, long after the build. The build now stops before it compiles anything (`cleat build` exits 1; the script behind it exits 3), naming both versions and the `pip install componentize-py==0.25.1` that fixes it. A version that cannot be read counts as a mismatch. To build with the version you have anyway, pass `--allow-unmeasured-componentize-py`, or set `CLEAT_ALLOW_UNMEASURED_COMPONENTIZE_PY=1` for a CI job or a container; the build then prints the warning and goes on. The flag is refused with any other `--target`. A script of yours that calls `python-sdk/scripts/build_wasm.py` directly takes the same flag and gets the same exit 3.
